# AI Use Declaration

AI tools were used during this project in a supporting role.

## Uses

- Debugging Python scripts and runtime errors.
- Language polishing for documentation and result descriptions.
- Suggesting code-quality checks such as `compileall`, dry-runs, and path validation.

## Non-Uses

- AI was not treated as an authoritative source for biological conclusions.
- AI-generated suggestions were reviewed and tested before inclusion.
- Final experimental design decisions, result interpretation, and submission responsibility remain with the project author.

## Responsibility Statement

The submitted artifact represents original project work. AI assistance was used as a development aid, comparable to debugging support and language polishing, not as a replacement for independent implementation and evaluation.
